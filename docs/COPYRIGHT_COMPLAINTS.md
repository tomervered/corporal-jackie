# Copyright complaints

This project publishes source code, release builds and documentation on GitHub. It hosts no videos, runs no add-on and keeps no index of streams, so it cannot remove a video from the internet or from an add-on.

## What you can report

- Something in this repository or its releases that you believe infringes your rights: code, images, text, test files or release notes.
- An add-on or stream source that this project names or links to anywhere it publishes.

## How to report

Open an issue at https://github.com/tomervered/corporal-jackie/issues and include:

1. Your name and how to reach you.
2. The work you own or represent.
3. The exact file, line, release or page in this project, with a link.
4. Why you believe it infringes.

If the issue would need to include something private, say so in the issue without the private details, and the maintainer will arrange another way to talk.

## What happens next

The maintainer reads reports and answers in the issue. Where a report concerns material this project published and holds up, that material is removed or changed and the issue says what was done.

Complaints about a video or a third-party add-on itself belong with whoever hosts it. GitHub also has its own process for content it hosts: https://docs.github.com/en/site-policy/content-removal-policies/dmca-takedown-policy
